# 견적서 확인·조정 가이드 (jin 10/5)

봇이 만든 견적서는 **고객에게 자동으로 나가지 않는다.** 직원이 아래 순서로 확인하고, 틀린 곳만 고쳐서 다시 계산한 뒤 직접 보낸다.

## 1. 어디서 보나

| 어디 | 무엇이 보이나 |
|---|---|
| 카톡 채널 답장 | 요약 (기간·날짜·인원 / 1인 단가·강당·펜션·온돌 / 총액·계약금·잔금) + **확인할 것** 목록 + [PDF] [사진] [시트 열기] 버튼 |
| 견적 시트 탭 (단체명 이름) | A~K열: 고객에게 나갈 견적서 그대로 |
| 같은 탭 **M3** | 자동작성 확인 메모 — 노란색이면 확인할 것이 있음 |
| 같은 탭 **M5** | 고객 요청 원문 |
| 같은 탭 **M8~N21 조정표** | 봇이 읽은 값 13칸 (연노랑 N열이 고칠 수 있는 칸) |

## 2. 무엇을 확인하나 (자주 틀리는 순서)

1. **인원** — 중고등·교사는 성인 수에, 미취학·초등만 '초등 이하'에. 범위(30~40명)는 큰 값으로 잡힘.
2. **날짜·박수** — 날짜 후보가 여럿이면 첫 번째로 잡힘. "1월 중순"처럼 대략이면 날짜 비어 있음(확인할 것에 뜸).
3. **단체종류** — 교회 / 회사(관공서·복지관·협회 포함, **부가세 포함**) / 대학(1박은 MT 단가) / 일반 / 여행사. 상호만 있는 단체(영문 이름 등)는 '일반'으로 잡히기 쉬움 → 회사면 고칠 것.
4. **바베큐·2인1실·대강당** — 요청글에 말이 있을 때만 켜짐.
5. **확인할 것 목록** — 노션 예약 겹침, 300명 초과, 대형 단체 특가(250명 이상, 전화로만), 양식에 펜션 줄 없음 등.

## 3. 어떻게 고치나 — 두 가지 방법

### 방법 ① 카톡으로 바로 (짧게 고칠 때)

```
수정: 인원 60, 아동 5, 단가 80000, 바베큐 빼기
```

| 쓰는 말 | 뜻 |
|---|---|
| `인원 60` | 성인(중고등 포함) 60명 |
| `아동 5` | 초등 이하 5명 (1인 2만 할인) |
| `단가 80000` / `단가 자동` | 1인 단가 직접 지정 / 자동 계산으로 되돌림 |
| `날짜 2026-11-13` | 체크인 날짜 (체크아웃은 박수로 자동) |
| `2박` / `당일` | 박 수 |
| `종류 회사` (교회·회사·대학·일반·여행사) | 단체종류 — 회사·여행사는 부가세 포함 |
| `바베큐` / `바베큐 빼기` | 바베큐 넣기·빼기 |
| `2인1실` / `2인1실 빼기` | 2인 1실 |
| `대강당` / `대강당 빼기` | 대강당 추가 대관 |
| `1강당 추가` | 추가 강당 |
| `객실 2실 추가` | 객실 추가 (1실 1박 6만) |
| `식사 1끼 빼기` | 1끼당 1인 −1만 (7~8월 불가) |
| `부가세` / `부가세 빼기` | 부가세 포함 여부 |

쉼표로 여러 개를 한 번에 쓸 수 있다. 못 알아들은 말은 답장에 따로 알려 준다.

### 방법 ② 시트 조정표 (여러 칸을 보면서 고칠 때)

1. 견적 탭 오른쪽 **M8~N21 조정표**의 **N열(연노랑)** 값을 고친다. (O/X 칸은 O 또는 X, 단가 칸은 비우면 자동)
2. 카톡 채널에 **`다시`** 를 보낸다.
3. 봇이 바뀐 칸만 골라 다시 계산하고 답장한다.

### 공통

- 고치면 **새 탭이 만들어지고 예전 탭은 지워진다.** (A~K열을 손으로 고친 내용도 같이 사라지니, 손으로 고칠 건 마지막에)
- 수정·다시는 **Gemini를 다시 부르지 않는다** — 처음 읽은 값에 고친 값만 덮어써서 계산하므로 빠르고, 다른 값이 바뀌지 않는다.
- 항상 **그 직원의 가장 최근 견적**에 적용된다. 다른 견적을 고치려면 그 요청글로 "견적:"을 다시 보낸다.
- 다 확인했으면 [PDF]·[사진] 버튼으로 받아 고객에게 직접 보낸다.
